## Update the existing record without creating a version

1. Open the existing [Zenodo dataset record](https://doi.org/10.5281/zenodo.23357963)
   and sign in with the record owner's account.
2. Choose **Edit** on the existing published record. Do not choose **New version**.
3. Keep Hamdam Aynazarov as the creator. Add Manar Mohaisen under **Contributors**, set
   the role to **Supervisor**, and enter **Northeastern Illinois University** as the
   affiliation.
4. Append the description text above without removing the current description or
   citation information.
5. Leave the files unchanged, review the metadata, and publish the metadata update on
   the existing record.
6. Reopen the DOI landing page and confirm the contributor and description appear and
   the DOI and files are unchanged.

Zenodo's current guidance permits editing metadata on a published record and states that
publishing the metadata changes does not affect its DOI. Versioning is used when creating
a separate versioned record, typically for updated files. See [Manage records](https://help.zenodo.org/docs/deposit/manage-records/)
and [Manage versions](https://help.zenodo.org/docs/deposit/manage-versions/).

This update is to be performed manually by the repository owner. Do not use an API token
or add account credentials to this repository.
